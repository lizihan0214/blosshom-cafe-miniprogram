# 简历项目说明

## 繁花咖啡门店扫码点餐小程序

**技术栈：** uni-app、Vue 2、JavaScript、Node.js、腾讯云 CloudBase、微信支付 API v3、芯烨云打印、Jest。

面向实体咖啡门店，推进扫码点餐小程序从需求设计到支付、打印联调，打通“扫码进入—选规格—购物车—微信支付—门店自动出单”流程。

- 实现动态菜单、冰量/糖分/茶底规格、按规格区分的持久化购物车及订单查询。
- 接入服务端可信计价、支付通知验签解密和主动查单；通过打印任务状态与条件更新控制重复发送。
- 优化缓存优先展示、后台刷新及图片加载，补充核心业务回归测试，支持门店菜单维护与迭代交付。
